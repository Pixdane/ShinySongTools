# SCSP 简体中文术语表

`scsp-zh-cn.linguagacha.json` 可直接导入 LinguaGacha。文件使用其标准术语表结构：

```json
[{"src": "原文", "dst": "译文", "info": "说明"}]
```

## 内容边界

- 人物名覆盖当前 dump 的 28 位《闪耀色彩》偶像、11 位 765PRO 联动角色、七草叶月和天井努。
- 人物全名同时收录普通半角空格与 `U+00A0 NO-BREAK SPACE` 两种源文写法。
- 人物名与组合名采用“偶像大师官方”中文账号当前公开使用的简体中文表记；其中 `斑鳩 ルカ` 必须译作“斑鸠琉花”，不沿用旧上游样例中的“斑鸠路加”。
- 游戏系统术语没有官方完整简体中文本地化可供照录；相关条目是根据 dump 和上游翻译样例收敛出的项目统一建议，并在 `info` 中明确标注。
- 模式名、服务名和 `LB` / `ST` / `PP` / `Me` / `Vo` / `Da` / `Vi` 等缩写保持原文。

## 主要来源

- LinguaGacha Wiki 的 Glossary 页面：确认 JSON 导入结构。
- “偶像大师官方”中文账号发布的《闪耀色彩》内容、官方哔哩哔哩收藏集及角色出演表：核对简体中文人物名与组合名。
- `ShinyGroup/SCSPTranslationData` 的 `TransData` / `DumpData`：发现候选游戏术语及互相冲突的旧译法。
- 本仓库 `resources/localization_manager_dic.json`：确认当前游戏内人物范围、原文写法和系统术语。

系统术语目前是翻译规则，不是官方译名。后续如获得正式简体中文游戏文本，应以正式文本为准逐项替换。
